## Что я проверил сам

Каждый кусок кода писался с ассистентом на основе материалов лекций и семинаров, использовались изученные методы.
Каждая ячейка запускалась вручную для проверки результатов. 

Проверила зерно основных таблиц и уникальность ключей (в таблице mobile-сегмента одна строка соответствует одному клиенту, в таблице подписок — одной подписке, в таблице платежей — одному платеж).
После соединений проверяла число строк и сумму выручки. Сумма платежа после исправления справочника тарифов совпала с действующей ценой для всех платежей.
Перед сдачей ноутбук запускала с чистого ядра через Restart Kernel and Run All Cells, чтобы проверить воспроизводимость всех расчётов и графиков сверху вниз.
